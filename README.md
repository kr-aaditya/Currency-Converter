# Currency-Converter
A currency converter made using html css and javascript.

The application allows users to enter an amount, select the source and target currencies, and convert the amount using exchange-rate data.

🚀 Features
💰 Convert between different currencies

🌍 Supports multiple countries and currencies

🔄 Select "From" and "To" currencies easily

📊 Displays the converted amount

🎨 Simple and responsive user interface

⚡ Built with vanilla JavaScript — no frameworks required


Live Demo : https://kr-aaditya.github.io/Currency-Converter/
🛠️ Technologies Used
HTML5 — Structure of the application

CSS3 — Styling and responsive design

JavaScript — Application logic and currency conversion

Exchange Rate API — Fetches current exchange-rate data

📁 Project Structure
currency-converter/
│
├── index.html      # Main webpage
├── style.css       # Styling and layout
├── app.js          # Application logic and currency conversion
├── codes.js        # Country and currency code data
└── README.md       # Project documentation

📖 How It Works
Enter the amount you want to convert.

Select the currency you are converting from.

Select the currency you want to convert to.

Click the get exchange rate button.

The application fetches the exchange rate and displays the converted amount.

The codes.js file contains the country/currency code information, while app.js handles the application's functionality and conversion logic.
